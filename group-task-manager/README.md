# TaskCircle

グループでタスクを共有できるiPhone向けのWebアプリです。**アカウント登録（メールアドレス・パスワード）は不要**で、名前を入力するだけで使えます。

## できること

- **参加コードでグループに入る** — グループを作ると6桁のコードが発行されます。他の人はそのコードを入力するだけで参加できます。
- **公開範囲を選べる** — タスクごとに「自分のみ」か「グループ公開」かを選べます。あとから切り替えることもできます。「自分のみ」のタスクは、URLを直接開かれても他の人には見えません。
- **メンバーにタスクを投げる** — 自分のタスクを、同じグループのメンバーに承認依頼として送れます。相手はアプリ内の「通知」タブで気づき、承認または却下できます。承認するとその人が担当者になります。
- **重複しているタスクがわかる** — タスク名を入力している最中に、グループ内の他のメンバーが同じようなタスクに取り組んでいないかを自動でチェックし、「◯◯さんも同じようなタスクに取り組んでいます」と表示します。一覧でも複数人で実施中のタスクにバッジが付きます。
- **ホーム画面に追加できる** — iPhoneのSafariで「ホーム画面に追加」すると、アプリのように全画面で使えます。

## 使い方（利用者向け）

1. デプロイしたURLを開き、名前を入力して「はじめる」
2. グループを作る（コードが発行されます）か、もらったコードを入力して参加する
3. 右下の「＋」からタスクを追加する

名前だけで本人を識別しているため、**別の端末・別のブラウザから開くと別の人として扱われます。**その場合はその端末でもう一度名前を入力し、参加コードでグループに入り直してください（設定タブから名前も変更できます）。

## デプロイ手順（Vercel）

このアプリはデータベースを使うため、静的ホスティング（GitHub Pagesなど）では動きません。Vercelなら無料枠でそのまま動かせます。

### 1. Vercelにプロジェクトを作る

1. [vercel.com](https://vercel.com) に GitHub アカウントでログイン
2. 「Add New…」→「Project」からこのリポジトリを選ぶ
3. **Root Directory に `group-task-manager` を指定**（リポジトリ直下ではありません）
4. まだ Deploy は押さずに、次の手順でデータベースを用意します

### 2. データベースをつなぐ

1. Vercelのプロジェクト画面で「Storage」タブを開く
2. Postgres（Neon など）を選んで作成する
3. 作成したデータベースをこのプロジェクトに接続する

接続すると `DATABASE_URL` が環境変数として自動で設定されます。手動で設定する場合は、Settings →  Environment Variables に以下を追加してください。

| 変数名 | 値 |
| --- | --- |
| `DATABASE_URL` | `postgresql://ユーザー:パスワード@ホスト/データベース?sslmode=require` |

> サーバーレス環境から接続するため、**プーリング対応の接続文字列**（Neonなら `-pooler` が付いたホスト）を使ってください。

### 3. デプロイする

「Deploy」を押すと、ビルド時に自動で以下が実行されます。

- `prisma generate` — DBクライアントの生成（`postinstall`）
- `prisma migrate deploy` — テーブルの作成（`build`）
- `next build` — アプリのビルド

完了すると `https://〇〇.vercel.app` のようなURLが発行されます。そのURLを一緒に使う人に共有すれば、全員が同じデータを見られます。

## ローカルで動かす

PostgreSQLが必要です。

```bash
cd group-task-manager
npm install
cp .env.example .env     # DATABASE_URL を自分の環境に合わせて書き換える
npx prisma migrate dev   # テーブルを作成
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。

## 技術構成

- Next.js 16（App Router / Server Actions）+ TypeScript
- PostgreSQL + Prisma 7（`@prisma/adapter-pg`）
- Tailwind CSS（iOS風のUI・ボトムタブ・セーフエリア対応）
- 本人確認はCookieのみ（パスワードもセッションサーバーも持ちません）

```
src/
  app/
    welcome/                名前の入力（初回のみ）
    (app)/groups            グループ一覧・作成・参加
    (app)/groups/[groupId]  タスク一覧（みんなのタスク / 自分のタスク / 通知）
    (app)/groups/[groupId]/tasks   タスクの作成・詳細（承認依頼・ステータス変更）
    (app)/notifications     通知一覧
    (app)/settings          表示名の変更・ログアウト
  actions/    Server Actions（本人確認・グループ・タスク・依頼・通知）
  lib/        DBクライアント、類似度判定、バリデーションなど
prisma/schema.prisma        データ定義
```

## 重複タスク検知のしくみ

タスク名を正規化（全角/半角・記号・空白の統一）したうえで、Levenshtein距離による類似度を計算し、しきい値以上、または一方が他方を含む場合に「同じタスク」とみなしています（`src/lib/similarity.ts`）。判定対象は同じグループ内の**「グループ公開」かつ未完了**のタスクのみで、「自分のみ」のタスクは比較に使われません。

## セキュリティについて

参加コードを知っている人は誰でもグループに入れます。社外に漏れて困る情報を扱う場合は、コードの共有範囲にご注意ください。
