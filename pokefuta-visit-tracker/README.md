# ポケふた訪問トラッカー

全国のポケモンマンホール「ポケふた」を地図・一覧で管理し、訪問済みかどうか・訪問日を記録できるWebアプリです。React + TypeScript + Vite + Leaflet(OpenStreetMap)で作られた、ブラウザだけで動く静的サイトです。

## 主な機能

- **地図ビュー**: OpenStreetMap上にポケふたをピン表示。訪問済み(緑)/未訪問(赤)で色分け、クラスタ表示、ポップアップから訪問トグル・訪問日入力・編集が可能
- **一覧ビュー**: 検索(名前・都道府県・ポケモン名)、都道府県フィルタ、訪問状態フィルタ、訪問トグル・訪問日編集
- **追加/編集フォーム**: 名前・都道府県・市区町村・住所メモ・ポケモン(タグ)・メモを入力し、ミニ地図のクリック/ピンのドラッグで緯度経度を設定
- **進捗・統計**: 総数に対する訪問済み数・達成率、都道府県別の内訳
- **インポート/エクスポート**: 全データ(訪問記録込み)をJSONファイルとして書き出し・読み込み。サンプルデータへのリセットも可能
- データはすべて**ブラウザのlocalStorage**に保存されます(サーバー不要)。別ブラウザ・別端末で使う場合はエクスポートしたJSONをインポートしてください。

## ⚠ データについての重要な注意

「ポケふた」は全国に800枚以上設置されていますが、このリポジトリが最初から収録しているデータ(`src/data/seedData.ts`)は**デモ用のサンプル**で、ポケふた発祥の地である鳥取県内の市町村を、市役所・駅付近の目安座標のみで収録したものです。設置されているポケモンの情報は誤りを避けるため空欄にしてあります。

実際に使う際は、必ず[ポケふた公式サイト](https://local.pokemon.jp/manhole/)などで正確な設置場所・ポケモンを確認したうえで、アプリの「編集」「+ 追加」機能から情報を修正・追加してください。追加したデータは「エクスポート」でJSONファイルに保存しておけば、次回起動時や別端末で「インポート」して復元できます。

## セットアップ

Node.js (v20以上推奨) が必要です。

```bash
cd pokefuta-visit-tracker
npm install
npm run dev
```

`http://localhost:5173` (実際のポート番号はターミナル出力を確認) をブラウザで開いてください。

## ビルド

```bash
npm run build
```

`dist/` ディレクトリに静的ファイルが生成されます。GitHub Pages・Netlify・Vercelなど、任意の静的ホスティングにそのまま配置できます。

## データのバックアップ形式

エクスポートされるJSONは以下の形式です(そのままインポート可能です)。

```json
{
  "version": 1,
  "exportedAt": "2026-08-16T00:00:00.000Z",
  "entries": [
    {
      "id": "seed-tottori-city",
      "name": "鳥取市のポケふた",
      "prefecture": "鳥取県",
      "city": "鳥取市",
      "address": "鳥取駅周辺(目安)",
      "lat": 35.5011,
      "lng": 134.2351,
      "pokemons": [],
      "note": "...",
      "verified": false,
      "visit": { "visited": false }
    }
  ]
}
```

## ディレクトリ構成

```
src/
  types/           型定義(Pokefuta, VisitInfo など)
  data/seedData.ts 初期サンプルデータ
  hooks/useAppData.ts  localStorage永続化・CRUD・インポート/エクスポート
  components/
    MapView.tsx    地図ビュー(react-leaflet)
    ListView.tsx   一覧ビュー
    EditModal.tsx  追加/編集フォーム
    StatsBar.tsx   進捗・統計表示
  App.tsx          画面全体の組み立て
```
