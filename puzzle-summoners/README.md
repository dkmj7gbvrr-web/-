# パズル召喚士（puzzle-summoners）

「パズル＆ドラゴンズ」のようなパズル×収集RPGのコンセプトを踏襲したWebアプリです。オーブを繋いで敵にダメージを与えるパズルバトルと、モンスターを集める**ガチャ**を中心に据えています。React + TypeScript + Viteで実装した、バックエンド不要のクライアントサイド完結アプリです（進行状況はブラウザのlocalStorageに保存されます）。

## できること

- **ガチャ召喚**: 魔法石を消費して1回・10連でモンスターを召喚できます。レアリティは1〜6★の6段階（排出率: 40/30/18/8/3/1%）。10連には**4★以上が最低1体確定**する保証枠があり、さらに通算50連引くごとに**5★以上が確定する天井**もあります。
- **モンスター収集**: 火・水・木・光・闇の5属性×6段階レアリティ、計30種類のモンスターを収録。ボックス画面で所持数（重複数）付きの図鑑として確認できます。
- **パーティ編成**: 最大5体編成。先頭（リーダー枠）のモンスターの「リーダースキル」が、そのモンスターの属性の攻撃力にチーム全体で倍率をかけます。
- **パズルバトル**: 6×5マスのオーブ盤面から1つオーブをつまんで隣接マスへドラッグで動かし、同色3つ以上を繋げて消すと攻撃になります（実機パズドラと同様、1個のオーブを持ち上げて経路上のオーブを押しのけながら移動する操作方式）。制限時間内は連続して動かせ、指を離すと消去・落下・連鎖判定を行います。
  - 消したオーブの数が多いほど（多消しボーナス）、コンボ数が多いほど（コンボボーナス）ダメージが増加します。
  - ハートオーブを消すとダメージの代わりにHPが回復します。
- **ダンジョン探索**: 3つのダンジョン×各4ステージ、計12ステージ。クリア報酬（魔法石・コイン）に加え、初回クリア限定でモンスターがドロップします。

## プロジェクト構成

```
src/
  game/
    types.ts        型定義（属性・レアリティ・モンスター・ステージなど）
    rng.ts           シード指定可能な疑似乱数生成器
    monsters.ts      モンスターのマスターデータ（30種類）
    gacha.ts         ガチャの抽選ロジック（排出率・10連保証・天井）
    board.ts         パズル盤面のロジック（生成・隣接判定・マッチ検出・連鎖処理）
    battle.ts         パーティのステータス計算・コンボからのダメージ／回復計算
    stages.ts         ダンジョン・ステージのマスターデータ
    orbTheme.ts       属性ごとの色・アイコン定義
    storage.ts        プレイヤー状態のlocalStorage永続化
    *.test.ts         上記ロジックのユニットテスト（Vitest）
  hooks/
    useGameState.ts   プレイヤー状態（所持石・コイン・所持モンスター・編成・進行）を管理するフック
  components/
    OrbBoard.tsx       オーブ盤面の描画とドラッグ操作（Pointer Events）
    BattleScreen.tsx   バトル画面全体（敵HP・コンボログ・勝敗判定）
    HpBar.tsx / MonsterCard.tsx  共通UIパーツ
    HomeScreen / GachaScreen / MonsterBoxScreen / PartyScreen / StageSelectScreen
    TabBar.tsx         画面下部のタブナビゲーション
  App.tsx              画面全体の組み立て
```

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（tsc + vite build）
npm run test      # Vitestでユニットテスト実行（ガチャ抽選・マッチ検出・ダメージ計算を検証）
npm run lint      # oxlint
```

## 実装メモ

- パズル盤面のマッチ検出は、行・列でのラン検出→同色で隣接するマス同士を結合、という実機パズドラに近いロジックで実装しています（L字やプラス字に繋がった5マスなどは1コンボとして扱われます）。
- ダメージ計算は `(コンボ数ボーナス) × Σ(属性別ATK × 多消しボーナス)` という簡略化した式です。リーダースキルはリーダーの属性のチーム合計攻撃力に倍率として乗算されます。
- ガチャ・盤面補充などすべての乱数は`rng.ts`のmulberry32（シード指定可能な疑似乱数生成器）を通しており、ロジック部分は`*.test.ts`から決定的に検証できます。
- モンスターにはレベルアップ要素を設けておらず、レアリティごとの基礎ステータスがそのままそのモンスターの強さになります（シンプルな収集育成サイクルを優先した設計です）。
