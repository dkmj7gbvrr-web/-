# 海の宝探し物語（umi-pachinko-game）

海をテーマにしたオリジナルデザインのパチンコシミュレーターです。React + TypeScript + Vite で実装した、バックエンド不要のクライアントサイド完結アプリです。

> **注記:** 実在するパチンコ機種（キャラクター・グラフィック・商標・音源）を再現したものではありません。始動チャッカー→デジタル抽選→大当たり→ラウンド継続→確率変動/時短といった、多くの現行パチンコ機に共通するゲームメカニクスを、海テーマのオリジナル要素で実装したものです。ボールの数（持ち球）はアプリ内だけの仮想の数値で、現金や景品との交換価値は一切ありません。

## できること

- **玉の発射**: ハンドル（発射強さスライダー）で強さを調整して発射。弱すぎるとレーンを登り切れず「ファール」になり、十分な強さで打つと釘盤に飛び込みます。
- **釘・盤面の物理シミュレーション**: 玉は重力と釘との衝突（不規則な跳ね返り）を受けながら盤面を落下します。
- **始動口とデジタル抽選**: 玉が始動口に入ると3桁のデジタル抽選が回転し、3つ揃うと大当たりです。図柄が奇数なら「確率変動」、偶数なら「時短」に突入します。
- **大当たり・ラウンド消化**: 大当たり中はアタッカーが開放され、玉を拾うたびに賞球を獲得。既定のラウンド数（3〜16R、抽選）を消化すると通常営業に戻ります。
- **確率変動・時短**: 確変中は次回大当たりまで当選確率がアップ（実機同様の「連チャン」を再現）。時短中は抽選の演出時間が短縮されます。
- **持ち球の管理**: 発射で1玉消費、入賞口・アタッカーで賞球を獲得。0になったら補充ボタンでリセットできます（仮想数値のみ）。
- **効果音**: Web Audio API によるオリジナルの合成音（実機の音源サンプリングではありません）。

## プロジェクト構成

```
src/
  game/
    types.ts       型定義・盤面サイズなどの定数
    odds.ts         大当たり確率・ラウンド数抽選テーブル
    physics.ts       玉の物理演算（重力・釘衝突・壁反射・発射レーン）
    board.ts         釘配置・入賞口/始動口/アタッカーの座標定義
    engine.ts         ゲーム状態の reducer（発射・抽選・大当たり・ラウンド進行・確変/時短）
    sound.ts          Web Audio API による効果音
    *.test.ts         上記ロジックのユニットテスト（Vitest）
  hooks/
    usePachinkoGame.ts  物理シミュレーションループとゲームエンジンを結びつけるフック
  components/
    Board.tsx          Canvas への盤面描画（釘・玉・アタッカー・始動口）
    ReelDisplay.tsx      デジタル抽選（3桁リール）の表示
    StatusPanel.tsx      持ち球・モード・ラウンド進行状況の表示
    Controls.tsx         発射強さスライダー・発射ボタン・連続発射・補充
  App.tsx              画面全体の組み立て
```

## ゲームロジックの設計メモ

- 大当たり確率は通常 1/99・確変中 1/40 としています（実機の海系スペックにある「確変は通常の約4倍当たりやすい」という比率は保ちつつ、ブラウザゲームとして遊びやすいよう確率自体は調整しています）。
- ラウンド数（3/5/10/16R）と大当たり図柄（0〜9、奇数=確変）は `src/game/odds.ts` の抽選テーブルに基づき、注入可能な乱数関数（`Rng`型）で決定されるため、`engine.test.ts` では決定的な乱数を与えて大当たり〜ラウンド消化〜確変突入までの一連の状態遷移を検証しています。
- 玉の物理は釘との衝突・壁反射・発射レーン（強さ不足だとファール）を `physics.ts` に純粋関数として実装し、Canvas 描画とは分離してテストしています。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（tsc + vite build）
npm run test      # Vitestでユニットテスト実行（抽選確率・状態遷移・物理演算の正しさを検証）
npm run lint      # oxlint
```
