# ナンプレ（nanpure-app）

難易度5段階・多彩な出題・メモ（鉛筆書き候補）機能・1手ずつ理由を説明するヒント機能を備えたナンプレ（数独）Webアプリです。React + TypeScript + Viteで実装した、バックエンド不要のクライアントサイド完結アプリです。

## できること

- **難易度選択（5段階）**: 初級・中級・上級・超上級・最難関。ヒントの数ではなく、その問題を解くのに必要な**解法テクニックの上限・下限**で難易度を判定して出題します。
- **多彩な出題**: 完成盤面をランダム生成し、一意解を保ったまま間引くため、実質無限に近いパターンの問題を生成します（毎回異なる盤面）。
- **メモ（候補）機能**: マスごとに1〜9の候補を鉛筆書き風に記録できます。数字を確定入力すると、同じ行・列・ブロックのメモから自動でその数字が消えます。
- **ヒント機能**: 「今の盤面でどこが理詰めで埋まるか／候補を絞り込めるか」を1手だけ、日本語の説明文とともに提示します。該当マスや候補をハイライトし、必要なら「入力する」「候補を消す」ボタンでそのまま盤面に反映できます。
- **戻す（undo）**: 数字の確定・メモの切り替え・消去・ヒント適用のたびに履歴を保持し、「戻す」ボタンまたは Ctrl/Cmd+Z で何手でも遡れます。
- **同じ問題で対戦**: ゲーム画面の「同じ問題で対戦（招待リンクをコピー）」から、今の問題を再現できるURLをコピーできます。友達がそのURLを開くと、乱数のseedをもとに完全に同一の盤面が生成されるため、同じ問題をそれぞれのデバイスで解いてタイムを競うといった遊び方ができます（進捗のリアルタイム共有はせず、それぞれ独立して解きます）。
- **誤答を即弾く**: 空マスに数字を確定入力した瞬間、盤面の正解と照合します。不正解なら盤面には反映せず、赤くシェイクして一瞬だけ表示したあとそのマスは空欄に戻ります（メモへの仮入力は対象外で、間違った数字も自由にメモできます）。
- 選択マスと同じ行・列・ブロックのハイライト、同じ数字のハイライト、入力ミス（重複）の自動検出。

## 難易度と解法テクニックの対応

問題生成時に、以下の人間的な解法テクニックだけを使って最後まで解けるかどうかをシミュレーションし、そのテクニックの難易度（ティア）が各レベルの範囲に収まるように問題を作っています。

| レベル | 名称 | 主に必要になるテクニック |
| --- | --- | --- |
| 1 | 初級 | 単一候補（ネイキッドシングル）・隠れ単一候補（ヒドゥンシングル） |
| 2 | 中級 | ポインティング／クレーミング（ブロックと行・列の候補の集中） |
| 3 | 上級 | ネイキッドペア／トリプル、ヒドゥンペア／トリプル |
| 4 | 超上級 | X-Wing、XY-Wing |
| 5 | 最難関 | 上記の全テクニックを使っても手詰まりになる、非常に手数の少ない問題 |

ヒント機能もこれと同じ解法エンジンを使っており、実装済みのテクニックで説明できる場合は必ずその理由を提示します。実装済みのテクニックでは説明できない高度な状態（最難関で起こりえます）になった場合のみ、正解の数字をそのまま開示するフォールバックになります。

## プロジェクト構成

```
src/
  sudoku/
    types.ts        型定義・難易度の説明文
    board.ts         盤面の基本ユーティリティ（行・列・ブロック、候補計算など）
    rng.ts            シード指定可能な疑似乱数生成器（同じ問題の再現に使用）
    solver.ts         バックトラッキングによる完成盤面生成・解の一意性判定
    techniques.ts      人間的解法テクニック（ヒント・難易度判定の共通エンジン）
    generator.ts       難易度別の問題生成（間引き＋難易度評価）
    engine.test.ts     上記のユニットテスト（Vitest）
  hooks/
    useSudokuGame.ts    ゲーム状態（盤面・メモ・タイマー・ヒント・履歴）を管理するフック
  components/
    DifficultySelector.tsx  難易度選択画面
    Board.tsx / Cell.tsx     盤面・マスの描画とハイライト
    NumberPad.tsx            数字入力・メモ切り替え・戻す・消去
    HintPanel.tsx             ヒントの説明表示・適用
    InviteShare.tsx           招待リンク（同じ問題を共有するURL）のコピー
  App.tsx               画面全体の組み立て・キーボード操作・共有URLの読み込み
```

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（tsc + vite build）
npm run test      # Vitestでユニットテスト実行（生成エンジンの正しさを検証）

```

## 実装メモ

- 完成盤面はバックトラッキング（MRVヒューリスティック＋乱数シャッフル）でランダム生成しています。
- 問題は、完成盤面から「一意解を保ちながら、指定した難易度の上限テクニックを超えない範囲でできるだけ間引く」方式で作成しています。間引きのたびに一意解判定と難易度判定を行うため、狙った難易度ぎりぎりの問題になりやすくなっています。
- ヒントは「今回のヒント要求からの候補の絞り込み」を内部で保持し、確定入力（実際の数字入力・盤面変更）があるとリセットされます。そのため同じヒントを求め続けても、論理的に先へ進むヒントが順番に提示されます。
- 問題生成のすべての乱数（完成盤面のランダム生成、間引き順）はseedから作った疑似乱数生成器（`rng.ts`のmulberry32）にのみ依存し、`Date.now()`のような実行環境依存の値は使っていません。そのため同じ難易度・同じseedを指定すれば、実行するデバイスやタイミングに関わらず常にビット単位で同一の問題を再現できます。「招待リンク」機能はこれを利用しており、URLの`?level=&seed=`をアプリ起動時に読み取って同じ問題を生成します。
