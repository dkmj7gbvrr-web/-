# 試験管パズル（test-tube-liquid-game）

バラバラに色が入った試験管の中身を、1色ずつ同じ試験管にまとめて整理する液体ソートパズルです。React + TypeScript + Viteで実装した、バックエンド不要のクライアントサイド完結アプリです。

## できること

- **4段階の難易度**: かんたん（4色）・ふつう（6色）・むずかしい（8色）・激ムズ（12色）。色数が増えるほど試験管の本数（色数＋空の試験管2本）も増えます。
- **操作**: 試験管をタップして選択し、もう一つタップすると、上に乗っている同色の液体のかたまりを、色が同じ（または空の）試験管へ注ぎます。容量（4）を超える分は注げず、入りきらない場合は入る分だけ移動します。
- **手数・タイムの記録**、**もどす（1手ずつundo）**、**はじめから（今の問題を最初の状態にリセット）**、**新しい問題（同じ難易度で別の問題を生成）**。
- クリア判定は「すべての試験管が空、または同じ色で満杯」になった時点。

## 出題ロジックと解けることの保証

`src/game/generator.ts` は、色ごとに容量分の球をランダムに試験管へ配ります（いわゆるランダムディール）。ただし配っただけでは解けない配置が生まれうるため、`src/game/solver.ts` の探索（深さ優先探索＋状態のメモ化・上限ノード数つきの完全解探索）で「最後まで注ぎきって全試験管をそろえられるか」を検証し、解けることが確認できるまで配り直します。そのため、遊べる問題は必ず最後まで解けることが保証されています（プレイヤーが途中で詰む手を選んだ場合は、「もどす」や「はじめから」で立て直せます）。

## プロジェクト構成

```
src/
  game/
    types.ts        型定義・難易度定義・色パレット
    engine.ts         注ぐ操作の基本ロジック（上の連続同色ブロックの判定・注げるか判定・注ぐ処理・クリア判定）
    solver.ts          深さ優先探索によるソルバー（解けるかどうかの検証に使用）
    generator.ts        ランダムディール＋ソルバーによる検証で出題を生成
    engine.test.ts      上記のユニットテスト（Vitest）
  hooks/
    useLiquidSortGame.ts  ゲーム状態（試験管・選択・手数・タイマー・履歴）を管理するフック
  components/
    DifficultySelector.tsx  難易度選択画面
    Tube.tsx                  試験管1本の描画（選択・クリア済みの見た目、アクセシビリティ用ラベル）
  App.tsx                 画面全体の組み立て
```

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（tsc + vite build）
npm run test      # Vitestでユニットテスト実行（注ぐロジック・ソルバー・出題生成の正しさを検証）
npm run lint      # oxlint
```
